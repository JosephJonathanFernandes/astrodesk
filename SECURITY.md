## Reporting a Vulnerability

We take the security of AstroDesk seriously. If you discover a security vulnerability, please follow these steps to report it:

1.  **Do not open a public issue.** Publicly reporting a vulnerability can put the community at risk.
2.  Email the details of the vulnerability to [josephjonathanfernandes@gmail.com](mailto:josephjonathanfernandes@gmail.com).
3.  Include as much information as possible, such as:
    *   The type of vulnerability (e.g., XSS, SQL Injection, RCE).
    *   Steps to reproduce the issue.
    *   Any relevant code snippets or screenshots.

## Response Timeline

*   We will acknowledge your report within 48 hours.
*   We will provide an estimated timeline for a fix within 1 week.
*   We will notify you once the fix has been released.

Thank you for helping keep AstroDesk secure!
